# Positron everywhere all at once

> A modern data science IDE has to feel the same wherever someone opens it. Data scientists move constantly between personal laptops, shared servers, containerized workflows, and the mix of cloud and on-prem environments that shape day-to-day work. The tools they rely on need to travel with them.

> Positron, a next-generation data science IDE, is one of those tools. Deploying it means meeting people on the platforms they already use. In this talk, I'll share strategies for bringing Positron to academic settings, where instructors and students juggle personal machines, course JupyterHub deployments, and department servers. I'll walk through real examples of running Positron Server through JupyterHub via jupyter-server-proxy, configuring it for classroom use, and weighing the tradeoffs of each approach. You'll leave with practical techniques for common academic deployment scenarios and a clearer sense of where Positron fits today.
